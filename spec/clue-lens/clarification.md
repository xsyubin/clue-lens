# 专卖监管线索分析与闭环管理需求澄清清单

> 本文档轻量记录经需求方确认的业务口径，作为后续技术需求细化与正式需求编写的输入。  
> 最后确认时间：2026-11-08

---

## 一、背景与目标

- **目标用户**：专卖局监督管理人员、情报分析人员、综合管理人员、线索核查执法人员以及部门负责人。
- **当前痛点**：
  1. 监管线索分散在各部门 Excel 台账中，格式标准不统一，检索困难；
  2. 区域分布与线索类型分析重度依赖人工手工统计汇总，效率低且时效性差；
  3. 重复出现的涉案经营主体或集中突发的区域异常难以及时发现；
  4. 重点线索流转无序，责任分派与办理时效缺乏跟踪闭环，易发生超期拖延；
  5. 周期性研判周报、月报需要重复机械整理。
- **预期价值**：通过 AI Coding 现场演示将脱敏 Excel 线索台账快速转化为具备“能查询、能分析、能流转、能闭环、能导出”的专卖监管全景业务小系统。
- **成功表现**：业务人员上传脱敏 Excel 台账后，系统秒级生成全景研判大盘，精准识别 5 类异常特征，辅助生成处置方案，完成“分派-办理-复核-归档”全链条闭环，并一键导出研判报告与台账。

## 三、用户角色与权限

系统采用**工作台全员协同共享 + 顶部快捷角色切换**机制。所有角色均可浏览全局宏观大盘，各角色的关键操作权限划分如下：

| 角色 | 主要目标 | 允许操作 | 数据可见范围 | 明确限制 |
| --- | --- | --- | --- | --- |
| **综合管理人员** | 台账统筹与任务分流 | 上传 Excel、导入纠错、线索分派（指派部门/责任人/办理期限/是否复核） | 全局线索、待分派线索池 | 不可代替核查人员填写核查处置结果 |
| **线索核查人员** | 现场调查与结果反馈 | 查看“我的待办”、登记核查时间/核查结果/处置措施、提交办结 | “我的待办”清单、本人经办线索、全局大盘 | 不可对线索执行分派与复核审批操作 |
| **部门负责人** | 重点监督与终审复核 | 复核审批（通过/驳回）、终审归档关闭、查看全盘超期与重点清单 | 全局线索、待复核清单、超期重点事项 | 驳回时必须录入复核驳回意见 |
| **情报分析人员** | 宏观洞察与辅助研判 | 异常特征探查、AI 处置建议生成与人工确认、导出分析研判报告初稿 | 全局线索、趋势大盘、类型/区域透视图 | 不直接参与一线办案流转操作 |
| **专卖监督管理人员** | 纪律监督与履职审计 | 全流程监控办理时效、查看超期预警、查阅全局审计留痕与时间轴 | 全局监控大盘、审计日志台账 | 审计日志只读，不可篡改或删除历史记录 |

## 四、核心业务流程

### 1. Excel 台账导入与解析流程

1. **触发条件**：综合管理人员点击“导入 Excel 台账”并上传文件。
2. **前置条件**：用户已登录且处于综合管理权限视角，上传文件格式为 `.xlsx`、`.xls` 或 `.csv`。
3. **主要步骤**：
   - 系统解析文件表头，按标准字段自动对齐匹配；
   - 逐行校验字段格式与数据类型；
   - 根据“线索编号”进行比对：已存在则更新对应字段（保留历史流转时间轴），不存在则新增记录；
   - 若出现单行校验错误，跳过该错误行并记录错误原因，继续导入其余有效数据。
4. **完成状态**：弹出导入结果面板，提示“导入成功 N 条，跳过异常 M 条”，刷新列表大盘。
5. **失败或取消**：若文件损坏或无任何有效表头，终止导入并给出阻断性格式错误提示，已有数据保持原样不变。

### 2. 线索全生命周期状态流转闭环

```text
[待分派 PENDING_ASSIGN]
       │
       ▼ (综合管理人员分派：指定责任部门/人/期限/是否复核)
[办理中 IN_PROGRESS] ◄────────────────────┐
       │                                  │ (复核驳回，退回并留痕)
       ├──────────────┬───────────────────┤
       │ (无需复核)   │ (需复核=是)        │
       │              ▼                   │
       │       [待复核 PENDING_REVIEW]────┘
       ▼              │ (复核通过)
[已完成 COMPLETED] ◄──┘
       │
       ▼ (部门负责人终审)
[已关闭 CLOSED]
```

1. **触发条件**：线索导入后默认处于“待分派”状态。
2. **前置条件**：操作人员切换至对应职责角色。
3. **主要步骤**：
   - **分派环节**：综合管理人员设置责任部门、责任人、办理期限与“是否需要复核”标志，状态变更为 `办理中`；
   - **办理环节**：核查人员在“我的待办”中录入核查结论、采取措施并提交；若“需复核=否”，状态直达 `已完成`；若“需复核=是”，流转至 `待复核`；
   - **复核环节**：部门负责人对 `待复核` 线索进行审核。审核通过进入 `已完成`；审核不通过录入驳回意见，状态退回 `办理中`；
   - **归档环节**：部门负责人对 `已完成` 线索执行最终归档，状态变更为 `已关闭`。
4. **完成状态**：线索流转时间轴完整沉淀全流程操作记录。
5. **失败或取消**：必填项未输入（如驳回时未填原因）阻止提交并标红提示。

## 五、功能与业务规则

### 1. 自动异常识别规则引擎

- **用户行为**：用户进入大盘或线索列表页，无需人工触发。
- **系统结果**：系统自动计算并在卡片及列表中打上高亮警示标签（支持作为筛选维度）。
- **业务规则判定口径**：
  1. **重复对象**：同一“经营对象”（名称或统一信用码/编号）在历史全部线索中出现频次 $\ge 2$ 次；
  2. **区域短期集中**：同一“所属区域”在过去 30 天内新增线索数量 $\ge 5$ 条；
  3. **同类连发**：同一区域近 30 天内同一“线索类型”累计达到 $\ge 3$ 条；
  4. **涉案金额异常**：线索“涉及金额”数值 $\ge 100,000$ 元；
  5. **办理超期预警**：当前系统日期 $>$ “办理期限”，且办理状态未处于 `已完成` 或 `已关闭`；
  6. **高风险未分派**：“风险等级”为 `高` 且“办理状态”为 `待分派`。
- **边界情况**：若线索未填写涉及金额或未指定办理期限，对应金额异常与超期预警规则不予触发。

### 2. 双模处置建议生成

- **用户行为**：分析人员或核查人员在线索详情页点击“生成处置建议”。
- **系统结果**：展示结构化处置方案建议卡片，包含建议方向、排查重点、处置措施及法条指引，用户可选择“采纳”、“编辑修改”或“忽略”。
- **业务规则**：
  - **默认离线专家规则基线**：内置专家决策树，根据“线索类型”（许可证异常、经营异常、配送异常、价格异常等）与“风险等级”（高/中/低）秒级生成标准化建议模板，无网络依赖，100% 稳定运行；
  - **可选 LLM 智能生成**：当系统环境变量配置有效大模型密钥时，允许用户勾选“AI 深度研判”，结合经营对象历史前科、区域频次等综合上下文生成定制化建议；
  - **人工确认原则**：建议内容仅供辅助参考，采纳后写入线索的“处置措施”草稿，必须由经办人员确认后才正式入库。

## 六、数据与业务口径

| 数据或指标 | 来源 | 业务定义与计算口径 | 更新时效 | 限制/枚举 |
| --- | --- | --- | --- | --- |
| **线索编号** | Excel导入/系统自增 | 线索全局唯一标识代码（如 `CLUE-2026-001`） | 导入即生成 | 唯一键，不可重复 |
| **风险等级** | Excel导入/人工调整 | 线索危险程度分类 | 实时 | 枚举：`高`、`中`、`低` |
| **办理状态** | 状态机流转驱动 | 当前处理进展阶段 | 状态流转时即时更新 | 枚举：`待分派`、`办理中`、`待复核`、`已完成`、`已关闭` |
| **线索类型** | Excel导入/人工选择 | 涉案业务场景类别 | 实时 | 枚举：`许可证异常`、`经营异常`、`配送异常`、`价格异常`、`非法收购`、`其他` |
| **线索来源** | Excel导入/人工选择 | 发现线索的初始渠道 | 实时 | 枚举：`日常检查`、`群众举报`、`数据分析`、`系统预警`、`部门移交` |
| **是否超期** | 规则引擎动态计算 | 当前系统日期 > 办理期限 且 状态未完成/未关闭 | 页面加载实时判定 | 布尔值（超期 / 正常） |
| **重复出现次数** | 系统动态聚合统计 | 该经营对象在全库中关联的线索总条数 | 每次导入或新增时自动重计 | 整数 $\ge 1$ |

## 七、输入与输出

- **输入方式**：
  - Excel/CSV 文件拖拽上传；
  - 表单录入与弹窗编辑（分派表单、办理填报表单、复核审批弹窗）；
  - 顶部角色快速切换下拉器。
- **输出形态**：
  - 首页综合态势分析看板（统计卡片、趋势图表、分布柱状图/饼图）；
  - 线索列表（支持表格视图与预警卡片视图切换）；
  - 线索详情流转时间轴（Timeline）；
  - 全局安全审计日志列表。
- **查询、筛选或排序**：
  - 支持多条件组合：所属区域、发现时间范围、线索类型、经营对象模糊搜索、风险等级、办理状态、责任部门、责任人、异常预警标签；
  - 排序：支持按发现日期倒序、办理期限升序（临期优先）、风险等级降序排列。
- **导入、导出与打印**：
  - **Excel 导入**：支持标准模板下载与自定义字段弹性容错映射；
  - **Excel 数据导出**：导出全量/筛选后明细及多维度聚合统计 Sheet；
  - **分析研判报告导出**：一键生成包含总体态势、重点高危对象、超期清单、成因分析与后续工作建议的 Markdown 文档及网页打印格式。

## 八、异常与非功能约束

- **空数据与无结果**：
  - 首次启动无数据时，引导下载“脱敏演示 Excel 模板”并上传；
  - 筛选无匹配项时，展示明确的空状态插画并提供“一键重置筛选”按钮。
- **无权限与越权防御**：
  - 界面操作按钮按当前角色视角自适应渲染（如核查人员视角隐藏“分派”按钮）；
  - 服务端 Server Actions 对当前操作者的角色与状态机合法性进行强校验，拦截非法状态跃迁。
- **冲突与重复控制**：
  - 导入时以“线索编号”为唯一键，重复时执行字段安全覆盖更新，不创建重复垃圾脏数据。
- **失败与重试**：
  - Excel 导入支持单行容错跳过，提供失败明细日志列表；
  - AI 建议生成若遇到超时或未配置密钥，自动无缝降级为专家规则库，业务无感知。
- **性能与容量约束**：
  - 本地 SQLite 支持单表 10,000+ 条线索秒级多维筛选；
  - 导入 1,000 条 Excel 数据处理时限 $\le 3$ 秒。
- **安全与合规审计**：
  - 所有演示数据均为脱敏或虚拟生成；
  - 系统记录敏感操作（分派、办结、驳回、导出）的操作人、操作类型、客户端 IP 与时间戳，形成不可篡改的全局审计日志。

## 十一、设计阶段输入

以下内容为技术设计阶段需要重点关注与落地的实现要求，不属于纯业务需求口径：

1. **底层引擎**：利用 Next.js 15 App Router + Drizzle ORM + SQLite (WAL模式) 实现轻量本地化开箱即用；
2. **Excel 解析**：采用前端/服务端无原生 C 依赖的高性能纯 JS/TS 库（如 `xlsx`）进行流式解析；
3. **状态机强校验**：Server Actions 需封装严格的 Guard 函数，确保状态跃迁只能沿既定图谱执行；
4. **离线高可用**：处置建议规则引擎设计为策略模式（`Strategy Pattern`），默认激活 `RuleBasedEngine`，环境检测到 LLM 配置时启用 `LLMEnhancedEngine`。
