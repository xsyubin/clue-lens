# 专卖监管线索分析与闭环管理小系统

## AI Coding 教学案例

## 一、案例目标

通过 AI Coding，现场将一份 Excel 线索台账快速转化为一个可运行的业务小系统，实现：

> 上传一份 Excel 线索数据 → AI 自动生成分析页面 → 按区域、时间、类型、对象进行筛选 → 自动识别异常 → 生成处置建议 → 分派责任人 → 跟踪办理状态 → 导出分析报告。

这个案例重点展示 AI Coding 如何帮助业务人员快速完成一个“能查询、能分析、能流转、能导出”的业务应用原型。

## 二、业务背景

目前专卖监管线索可能分散在不同部门的 Excel 台账中，常见问题包括：

- 数据格式不统一
- 线索查询效率低
- 区域和类型分析依赖人工汇总
- 重复出现的异常对象不容易发现
- 重点线索缺少统一标记
- 责任人和办理进度难以跟踪
- 周报、月报需要重复整理

因此，需要建设一个轻量化的“专卖监管线索分析与闭环管理小系统”。

## 三、系统使用角色

- 情报分析人员
- 专卖监督管理人员
- 综合管理人员
- 线索核查人员
- 部门负责人

## 四、核心功能

### 1. Excel 数据导入

上传脱敏后的 Excel 线索数据，系统完成字段识别、格式校验和批量导入。

### 2. 多条件筛选

支持按照以下条件筛选：

- 区域
- 发现时间
- 线索类型
- 经营对象
- 风险等级
- 办理状态
- 责任部门
- 责任人

### 3. 自动异常识别

系统根据预设规则辅助识别异常，例如：

- 同一对象重复出现
- 同一区域短期内线索集中出现
- 同类问题连续发生
- 涉及金额异常
- 办理事项超过期限
- 高风险线索尚未分派

### 4. 处置建议生成

根据线索类型、风险等级和历史办理情况，生成辅助性的处置建议，例如：

- 建议进一步核查经营主体
- 建议进行现场检查
- 建议补充相关材料
- 建议转交指定部门
- 建议纳入重点跟踪

处置建议仅作为辅助信息，最终结论由业务人员确认。

### 5. 责任人分派

支持为线索设置：

- 责任部门
- 责任人
- 办理期限
- 优先级
- 是否需要复核

### 6. 办理闭环

线索状态建议包括：

```text
待分派 → 办理中 → 待复核 → 已完成 → 已关闭
```

同时记录：

- 核查时间
- 核查人员
- 核查结果
- 处置措施
- 复核意见
- 完成时间

### 7. 分析报告导出

支持导出：

- 线索明细
- 区域分析
- 类型分析
- 重点线索清单
- 超期事项清单
- 办理进度统计
- 周报或月报分析初稿

## 五、建议数据字段

| 字段         | 说明                                   |
| ------------ | -------------------------------------- |
| 线索编号     | 每条线索的唯一编号                     |
| 发现日期     | 线索发现时间                           |
| 所属区域     | 线索所属区域                           |
| 线索来源     | 检查、举报、数据分析、系统预警等       |
| 线索类型     | 许可证、经营异常、配送异常、价格异常等 |
| 经营对象     | 使用虚拟名称或编号                     |
| 风险等级     | 高、中、低                             |
| 涉及金额     | 使用虚拟金额                           |
| 重复出现次数 | 同一对象或同类问题出现次数             |
| 责任部门     | 负责办理的部门                         |
| 责任人       | 负责办理的人员                         |
| 办理期限     | 要求完成的日期                         |
| 办理状态     | 待分派、办理中、待复核、已完成、已关闭 |
| 核查结果     | 核查结论                               |
| 处置措施     | 采取的处理方式                         |
| 是否超期     | 根据办理期限自动计算                   |
| 备注         | 补充说明                               |

## 六、演示流程

### 第一步：上传 Excel

上传一份脱敏线索数据，要求系统识别字段并完成数据导入。

### 第二步：生成分析页面

让 AI 生成首页，至少展示：

- 线索总数
- 高风险线索数
- 待办理线索数
- 超期线索数
- 各区域分布
- 各类型 TOP N
- 线索趋势

### 第三步：筛选查询

现场演示以下查询：

- 查看某个区域的全部线索
- 查看某个月发现的线索
- 查看某一类异常问题
- 查看某个经营对象的历史记录
- 查看全部高风险且未完成的线索

### 第四步：异常识别

让 AI 根据规则识别：

- 重复出现对象
- 短期集中出现区域
- 连续发生的问题类型
- 高风险未处理事项
- 超期办理事项

### 第五步：生成处置建议

打开某条重点线索，由 AI 根据线索信息生成处置建议，并允许业务人员修改、确认或忽略。

### 第六步：分派责任人

为重点线索分派责任部门、责任人和办理期限。

### 第七步：跟踪办理状态

演示状态变化：

```text
待分派 → 办理中 → 待复核 → 已完成
```

同时查看：

- 我的待办
- 即将超期
- 已超期
- 待复核事项
- 各部门办理进度

### 第八步：导出分析报告

按区域或时间范围导出线索分析报告，报告至少包含：

- 总体情况
- 区域分布
- 类型分布
- 重点问题
- 办理进度
- 超期事项
- 后续处置建议

## 验收标准

案例完成后，至少满足以下要求：

- 可以成功导入脱敏 Excel 数据。
- 可以按区域、时间、类型和对象筛选。
- 可以展示线索统计和趋势分析。
- 可以识别重复、集中、超期等异常。
- 可以生成辅助处置建议。
- 可以分派责任人和设置办理期限。
- 可以跟踪线索办理状态。
- 可以查看超期和待复核事项。
- 可以导出明细和分析报告。
- 关键操作有日志记录。
- 所有演示数据均为虚构或脱敏数据。
